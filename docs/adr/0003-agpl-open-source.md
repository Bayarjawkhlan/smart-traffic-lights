# The project is AGPL-3.0 open source

The vision service uses Ultralytics YOLO, which is AGPL-3.0, so the whole project is published under AGPL-3.0 rather than buying an Ultralytics commercial license or using a permissive detector. This suits a portfolio and demo project. If the project is ever sold or run by the city, revisit this: the vision service only emits counts, so swapping YOLO for an Apache-2.0 detector (RT-DETR, YOLOX) is contained to that service.
